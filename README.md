## Описание
Консольное приложение «Анализатор оценок» на языке Dart. Проект осуществляет расчёт средних, максимальных и минимальных баллов студентов, а также выводит итоговую буквенно-текстовую оценку.

## Запуск
1. Клонировать репозиторий: `git clone <url_вашего_репозитория>`
2. Перейти в папку: `cd lab1_dart`
3. Установить зависимости: `dart pub get`
4. Запустить: `dart run`

## Что было изучено

* Механизм Sound Null Safety для предотвращения ошибок обращения к null.
* Работа со стрелочными, анонимными функциями и именованными параметрами.
* Использование базовых коллекций (`List`, `Map`, `Set`).

## Ответы на вопросы
1. В Dart тип переменной известен на этапе компиляции, тогда как в Python он динамический и определяется во время выполнения. Главное преимущество — компилятор находит ошибки несовместимости типов заранее, повышая стабильность приложения.

2. `String?` (с вопросительным знаком) является nullable-типом, то есть переменная может принимать значение `null`. Обычный тип `String` гарантированно никогда не может быть равен `null`.

3. Ключевое слово `final` защищает данные на уровне языка и компилятора. Если разработчик попытается случайно перезаписать `final`-переменную, программа просто не скомпилируется. В Python такие соглашения держатся только на честном слове разработчика.

4. Именованный параметр передается по ключу при вызове, а не по порядку, а ключевое слово `required` делает его обязательным (без него код не запустится). 
   Пример вызова: `printStats(name: 'Артём', grades: [5, 4]);`
